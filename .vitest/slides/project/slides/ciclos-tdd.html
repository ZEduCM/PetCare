Ciclos de TDD no repositório

Três ciclos, um por autora, cada um com um commit só de teste seguido de um commit só de correção. O histórico tem onze ciclos no total.

CicloDefeitoVermelho (teste)Verde (correção)Autora

3DEF-14: rota inexistente mostra página 404d4298fb · test: reproduce DEF-14 unknown route68718c8 · fix: show 404 for unknown routesCamila

Os commits são feitos na conta de cada integrante. As mensagens test:, fix: e refactor: marcam as três fases do ciclo, então o histórico do Git é a evidência do processo.

Critério Habilidade: aplicação correta do ciclo. Mostrar o git log filtrado se houver tempo: git log --oneline, e apontar os pares test e fix. Cada ciclo nasceu de um defeito real encontrado nos testes, registrado antes como falha esperada. O próximo slide demonstra o ciclo 2 ao vivo.
