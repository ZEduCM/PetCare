Rastreabilidade por requisito

Relatório gerado a partir da execução real: 264 testes do Vitest e do Playwright, 9 de 9 requisitos cumpridos. Clicar num requisito mostra só os testes dele, com arquivo e linha.

Esta tela é gerada pelo próprio projeto a partir das tags dos testes. Cada cartão soma os testes que carregam a tag do requisito e mostra quantos passaram. Se um requisito ficasse sem teste, apareceria "Sem testes" em amarelo. Vale abrir ao vivo: npm run test:report e npm run test:report:open, depois requisitos.html, e clicar em RF-07 para filtrar.
